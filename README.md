# Ясно — Концепт сайта функциональной кофейни

Концепт команды «Есть что показать»: так может выглядеть онлайн функциональная кофейня.
Название и детали придуманы, это не сайт реального бизнеса.

Один стол, один день: шесть сцен от утренней чашки до вечернего чая и в конце «стол у окна ждёт».
Статический сайт без сборки: `index.html`, шрифты, изображения. Открывается через любой веб-сервер.
